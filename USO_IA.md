# AstroBaseS2
Página Web Sumativa 2, Front End.

Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- DOM
- Validaciones
- Arreglos y Objetos


Uso de Inteligencia Artificial
Durante el desarrollo del proyecto se utilizó ChatGPT como apoyo para:
- Mejorar validaciones JavaScript
- Crear efectos visuales modernos
- Refactorizar funciones
- Mejorar seguridad del DOM
- Crear estructura modular

- ## Prompt 1 
Crea una página web moderna sobre astronomía llamada AstroBase. Debe verse profesional, futurista y elegante, usando HTML, CSS y JavaScript separados en distintos archivos, con Html5, css3, javascript vanilla.

---

## Prompt 2 
Haz que el diseño tenga temática espacial, con fondo oscuro tipo galaxia, estrellas animadas y colores dorado, azul oscuro y negro. Que se vea premium y moderno.

---

## Prompt 3  
Crea un formulario para registrar observaciones astronómicas con los siguientes campos:
- Nombre del objeto
- Tipo de objeto
- Fecha
- Ubicación
- Email observador

Debe tener validaciones usando JavaScript.

---

## Prompt 4 
Haz que el formulario sea inteligente: no dejes que se guarde la información si hay cuadros vacíos, si el nombre es muy corto o si el formato del correo electrónico está mal escrito (que tenga el @ y el punto).

---

## Prompt 5  
Implementa buenas prácticas de seguridad en JavaScript evitando usar innerHTML peligroso. Usa textContent y createElement para evitar vulnerabilidades XSS.

---

## Prompt 6 
Asegúrate de que la página sea segura y que no se pueda 'hackear' metiendo código malicioso en los cuadros de texto. Para mostrar los datos en las tarjetas, no uses innerHTML; usa mejor comandos como textContent o createElement para que el navegador solo escriba texto y nada más.

---

## Prompt 7 
Guarda toda la información de los registros usando arreglos y objetos en JavaScript, para que cada observación astronómica sea como una ficha organizada que se pueda manejar fácilmente en el código.

---

## Prompt 8 
Crea funciones que sirvan para varias cosas a la vez, como una para dibujar las tarjetas en la pantalla (renderizar), otra para revisar que el formulario esté bien escrito y otra para limpiar los cuadros de texto después de guardar, así el código no se repite tanto y queda más ordenado

---

## Prompt 9 
Las observaciones deben mostrarse como tarjetas dinámicas modernas con diseño espacial y animaciones suaves.

---

## Prompt 10 
Agrega un botón 'Comenzar misión' que haga scroll suave hacia abajo, mostrando lentamente la página en vez de saltar instantáneamente.

---

## Prompt 11 
Agrégale efectos visuales llamativos para que se vea moderna: que las cosas aparezcan suavemente al bajar por la página, que los botones brillen en dorado y cambien cuando les pase el mouse por encima, y que el fondo tenga estrellas que se muevan para que parezca el espacio

---

## Prompt 12 
Agrega una sección de curiosidades o tips astronómicos tipo:
'Sabías que...' mientras el usuario llena el formulario.

---

## Prompt 13 
Cuando el usuario haga clic en un input, debe aparecer un pequeño mensaje de ayuda cerca del campo con ejemplos de cómo escribir.

Ejemplos:
- Nombre del objeto : 'Ej: Antares'
- Ubicación : 'Ej: Maipú, Santiago / Patio / Observatorio'

---

## Prompt 14 
En el select de tipo de objeto agrega una opción 'Otro'. Si el usuario selecciona 'Otro', debe aparecer automáticamente un nuevo input para escribir el tipo personalizado.

---

## Prompt 15 
Haz que toda la página sea responsive y funcione correctamente en celulares, tablets y computadores.

---

## Prompt 16 
Haz que AstroBase parezca una plataforma real y profesional de exploración astronómica.

---

## Prompt 17 
Agregar footer con los nombres:
Constanza Casté y Maximiliano Bascuñán.

---

## Prompt 18 
Mejora la experiencia visual usando transiciones suaves, bordes redondeados, transparencias y animaciones elegantes.

---

## Prompt 19 
Mejora la interfaz para que el formulario sea claro, moderno y fácil de usar sin perder la estética espacial.

---

## Prompt 20 
Ayúdame a terminar la AstroBase revisando que cumpla con todo lo que pide la rúbrica: que los datos se vean en tarjetas automáticamente (DOM dinámico), que el formulario no deje pasar errores (validaciones), que la página sea segura contra ataques (seguridad), que toda la información esté bien organizada (arreglos y objetos) y que se vea bien tanto en el computador como en el celular (diseño responsive).
